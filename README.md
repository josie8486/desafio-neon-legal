# Página legal do Desafio Neon

Esta pasta contém uma página estática, leve e sem rastreadores com **Política de Privacidade**, **Termos de Uso** e **Suporte**. O contato público autorizado é `gdarellekasiah@gmail.com`.

## Opção recomendada: GitHub Pages

O GitHub Pages é gratuito para repositórios públicos e fornece HTTPS. Crie um repositório chamado `desafio-neon-legal`, envie `index.html` e `style.css`, abra **Settings > Pages**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/root`. A URL será parecida com `https://SEU-USUARIO.github.io/desafio-neon-legal/`.

Essa URL pode ser usada no campo **Política de privacidade** da ficha do Google Play. A página deve permanecer pública, ativa, sem login e editável como página web — não use um PDF.

## Alternativas gratuitas

| Serviço | Vantagem | Observação |
|---|---|---|
| GitHub Pages | Simples, HTTPS e controle de versão | Repositório público no plano gratuito |
| Cloudflare Pages | HTTPS e publicação rápida | Exige criar/conectar uma conta Cloudflare |
| Netlify | Arrastar a pasta e publicar | A URL gratuita usa subdomínio Netlify |

## Arquivos que devem ser enviados

- `index.html`
- `style.css`

Não envie o APK, o AAB, a chave `.jks` nem arquivos de senha para o repositório da política.

## Depois de publicar

1. Abra a URL em uma janela anônima e confirme que não há login.
2. Verifique o texto em um celular.
3. Copie a mesma URL para **Play Console > Conteúdo do app > Política de Privacidade** e para a página principal de detalhes do app, se o campo for solicitado.
4. Mantenha a página no ar enquanto o aplicativo estiver distribuído.

Fontes oficiais: [Política de privacidade e dados do usuário](https://support.google.com/googleplay/android-developer/answer/10144311?hl=pt-BR) e [GitHub Pages](https://pages.github.com/).
